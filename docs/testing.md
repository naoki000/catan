## Roblox Studio での確認手順（Server & Clients）

1. Rojo で同期（README 参照）し、テスト → クライアントとサーバー → プレイヤー数 3（または 4）→ 開始
2. 以下を順に確認し、結果を下表に記入してください

| 確認内容 | 結果 |
|---|---|
| 出力ウィンドウに `[Hexland] server mode: local` と表示される | |
| Player1 で部屋を作成 → 部屋コードが表示される | |
| Player2/3 がコードで参加 → 全員のロビーに色付きで3人表示 | |
